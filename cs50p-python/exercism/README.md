# Exercism — Per-concept Python drills

Used as a supplement to CS50P. After each lecture, I do 2-3 Exercism exercises on the same concept to drill it deeper before moving on.

## Setup

1. Sign up at [exercism.io](https://exercism.io)
2. Install the CLI: `brew install exercism` (or follow their install instructions)
3. Configure: `exercism configure --token=YOUR_TOKEN`
4. Download an exercise: `exercism download --exercise=leap --track=python`

## Folder layout

Each Exercism exercise gets dropped into its own folder by the CLI. I've pre-created topic folders to organize them.

## Rule

Exercism exercises don't count if I peek at the community solutions before solving them. Submit my own first, *then* I can compare.
