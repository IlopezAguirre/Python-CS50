# Scratchpad

Junk drawer. Where broken code, half-finished experiments, and "what does this do?" tests live.

**Rules:**
- Nothing here is graded or polished
- Don't worry about clean code
- This is where you try weird ideas before they're ready for `practice/`
- Files can be deleted any time

If something here turns into a real practice file, move it to the right week's `practice/` folder and clean it up there.
