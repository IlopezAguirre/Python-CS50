# CS50P — Introduction to Programming with Python

My journey through Harvard's CS50P, paired with Exercism for per-concept reps.

**Started:** May 10, 2026
**Goal:** Complete CS50P + final project by mid-June, then move to Level 2 of the ML roadmap.

## Why this repo

I'm rebuilding my Python foundation from scratch. I've used AI tools heavily in past projects, and this is where I learn to write Python without them. Every line of code in this repo is typed by hand. No copy-paste from videos. No AI for learning blocks.

## Structure

Each week gets its own folder. Inside:

- `lecture-notes/` — my own notes from the lecture, written in my own words
- `practice/` — small per-concept exercises (one file per concept)
- `problem-set/` — the official CS50P problem set submissions

Plus:

- `exercism/` — supplementary per-concept drills from Exercism's Python track
- `final-project/` — the capstone CS50P project
- `_scratchpad/` — junk code, experiments, broken stuff (ignored from main view)
- `_logs/` — daily reflection logs
